# Founder Photo Folder

`/public/founder/IMG_3226.jpeg`
or
`/public/images/founder/IMG_3226.jpeg`

1. `/founder/IMG_3226.jpeg`
2. `/images/founder/IMG_3226.jpeg`
3. `/images/founder.jpg` or `.png`
4. Client-side uploaded photo saved via the instant photo picker on the website.
